## English

Code for two short looping films made with AI-generated video and object detection.
Footage of people and buildings generated with Runway is turned into simple 3D using AI-estimated depth, the scenes are joined with morphs, and the results of real computer-vision analysis (YOLO object detection and more) are layered on top as effects.

### How it works

1. **Generate the footage** (`runway_gen.py`)
   Images and videos of people and buildings are generated with Runway. Each morph between scenes is generated by giving the last frame of one scene and the first frame of the next (h3_max keyframe mode).
2. **Estimate depth** (`film_prep.py`)
   Depth Anything V2 estimates depth, which is turned into distances on an 800×450 grid. Video is normalised across all frames at once so the distances don't wobble.
3. **Build depth meshes** (`film_scene.py`, Blender 4.5)
   The photo is mapped onto a mesh, and faces where depth jumps sharply are torn. An untorn copy sits slightly behind, so the tears fill with streaks of stretched pixels. Every segment's camera starts and ends at the photo's own viewpoint, so the joins can't be seen.
4. **Join the segments** (`film_edit.py`, layout in `film_plans.py`)
   Scenes and morphs are joined with 6-frame overlaps into a loop.
5. **Analyse** (`analyze.py`)
   YOLO-World and YOLO11 detect and track objects; SAM 2.1 makes masks; surface normals come from depth gradients; ORB finds feature points.
6. **Composite and finish** (`film_composite.py`)
   The analysis is drawn as boxes and labels, lavender normal-map fills, a green silhouette on yellow, and lines between points. During morphs the person's head leaves a trail. Finally the colour is graded and the film is exported.

### Requirements

- macOS (tested on Apple Silicon)
- Blender 4.5 (`/Applications/Blender.app`)
- Python 3 with the packages in `requirements.txt`
- ffmpeg
- A Runway API key, only if you want to regenerate the footage

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

The detection and mask models (YOLO-World v2, YOLO11m, SAM 2.1 base) are downloaded into `models/` on the first run.

Pass the Runway API key in the environment variable `RUNWAYML_API_SECRET`, or write `RUNWAYML_API_SECRET=...` in a `.env` file in this folder (`.env` is not tracked by Git). By default `runway_gen.py` only prints the estimated cost and your balance; it generates only with `--run`.

### Running

Once the footage is in place, prepare each scene, render the segments, then join and finish each film.

```bash
.venv/bin/python film_prep.py video walker runway/walker.mp4 2 80
/Applications/Blender.app/Contents/MacOS/Blender -b -P film_scene.py -- walker2
.venv/bin/python film_edit.py people
.venv/bin/python analyze.py peoplebase
.venv/bin/python film_composite.py people
```

To rebuild both films at once, use `scripts/run_cam.sh` (re-renders only the scene segments) or `scripts/run_both.sh`.

## 日本語

AI で生成した動画と物体検出の技術を使って作った、2本のループ映像の制作コードです。
Runway で生成した人物と建物の映像を、AI で推定した奥行きで簡易的に3D化し、場面と場面をモーフィングでつないだ上に、物体検出（YOLO）などの解析結果をエフェクトとして重ねています。

### 作り方

1. **素材を作る**（`runway_gen.py`）
   Runway で人物と建物の画像・動画を生成します。場面の間のモーフは、前の場面の最後のコマと次の場面の最初のコマを指定して生成します（h3_max のキーフレーム指定）。
2. **奥行きを推定する**（`film_prep.py`）
   Depth Anything V2 で深度を推定し、800×450 の格子の距離にします。動画は全コマまとめて正規化し、距離が揺れないようにしています。
3. **深度メッシュにする**（`film_scene.py`、Blender 4.5）
   写真を貼ったメッシュを作り、奥行きが急に変わる面は破ります。少し奥に破らない複製を置き、裂け目が引き伸ばされた画素の筋で埋まるようにしています。カメラはどの区間も写真と同じ視点で始まって終わるので、つなぎ目は見えません。
4. **つなぐ**（`film_edit.py`、構成は `film_plans.py`）
   場面とモーフを6コマ重ねてつなぎ、ループにします。
5. **解析する**（`analyze.py`）
   YOLO-World と YOLO11 で物体を検出して追跡し、SAM 2.1 でマスク、深度の勾配で面の向き、ORB で特徴点を取ります。
6. **重ねて仕上げる**（`film_composite.py`）
   解析結果を枠とラベル、ラベンダー色の面の向き、黄色地に緑の人型、点を結ぶ線として重ね、モーフ中は人物の頭の残像を並べます。最後に色を整えて書き出します。

### 必要なもの

- macOS（Apple Silicon で確認）
- Blender 4.5（`/Applications/Blender.app`）
- Python 3 と `requirements.txt` のパッケージ
- ffmpeg
- 素材を作り直す場合は Runway API のキー

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

物体検出とマスクのモデル（YOLO-World v2、YOLO11m、SAM 2.1 base）は、初回実行時に `models/` へダウンロードされます。

Runway API のキーは環境変数 `RUNWAYML_API_SECRET` で渡すか、このフォルダの `.env` に `RUNWAYML_API_SECRET=...` と書きます（`.env` は Git に含めません）。`runway_gen.py` は既定では見積もりと残高を表示するだけで、`--run` を付けたときだけ生成します。

### 実行

素材を用意したあと、各場面を準備して区間を描き、作品ごとにつないで仕上げます。

```bash
.venv/bin/python film_prep.py video walker runway/walker.mp4 2 80
/Applications/Blender.app/Contents/MacOS/Blender -b -P film_scene.py -- walker2
.venv/bin/python film_edit.py people
.venv/bin/python analyze.py peoplebase
.venv/bin/python film_composite.py people
```

両作品をまとめて作り直すときは `scripts/run_cam.sh`（場面の区間だけ描き直す）か `scripts/run_both.sh` を使います。
